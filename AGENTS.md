# AGENTS.md

## Project Overview

`ha-on-echo-show` is an AWS Lambda-backed Alexa Skill that opens Home Assistant Lovelace dashboards and camera views on an Amazon Echo Show using Alexa Presentation Language (APL) `OpenURL` commands in the built-in Silk browser.

## Tech Stack

- **Runtime**: Node.js 26 (`nodejs26.x` on AWS Lambda), ES Modules (`"type": "module"`).
- **Frameworks & SDKs**:
  - `ask-sdk-core` / `ask-sdk-model` (Alexa Skills Kit SDK v2 for Node.js)
  - `serverless` v4 (AWS Lambda deployment via `serverless.yml`, installed in `devDependencies`)
- **Linting & Formatting**: ESLint (`eslint-config-standard` + `eslint-plugin-prettier`) and Prettier.

## Repository Structure

```text
.
├── index.js                              # Lambda entry point & SkillBuilder handler registration
├── serverless.yml                        # Serverless Framework v4 config (AWS Lambda + Alexa trigger)
├── documents/
│   └── launchDocument.json               # Minimal APL 1.9 document required to run APL commands
└── src/
    ├── actions/echo-show/open-url.js     # APL RenderDocument + ExecuteCommands (OpenURL) helper
    ├── intents/
    │   ├── launchRequestHandler.js       # Opens HA_ENDPOINT/lovelace/default_view on LaunchRequest
    │   ├── openPageIntentHandler.js      # Handles OpenPageIntent (reads `page` slot)
    │   ├── helpIntentHandler.js          # Handles AMAZON.HelpIntent
    │   ├── cancelAndStopIntentHandler.js # Handles AMAZON.CancelIntent / AMAZON.StopIntent
    │   └── fallbackIntentHandler.js      # Handles AMAZON.FallbackIntent
    ├── sessionEndedRequestHandler.js     # Handles SessionEndedRequest
    └── errorHandler.js                   # Global Alexa skill error handler
```

## Code Style & Conventions

- **Formatting**: Enforced by `.editorconfig`, `.eslintrc.yml`, and `.prettierrc`:
  - **Tabs** for indentation (`indent: ['error', 'tab']`).
  - **Single quotes**, **no semicolons**, LF line endings.
  - Run `npm run lint` after editing JavaScript files.
- **ESM Imports**: Always include explicit `.js` extensions on relative imports (e.g., `import { openURL } from '../actions/echo-show/open-url.js'`). JSON files in ESM are currently loaded via `createRequire(import.meta.url)` (see `src/actions/echo-show/open-url.js`).
- **Alexa Handler Registration**: Every new handler added under `src/intents/` must be imported and registered in `index.js` inside `Alexa.SkillBuilders.custom().addRequestHandlers(...)`. Order matters: register specific handlers **before** `FallbackIntentHandler`.
- **Voice Response Locale**: Custom user-facing speech outputs are in Brazilian Portuguese (`pt-BR`). Keep new user-facing responses consistent with `pt-BR`.

## Configuration & Secrets

Runtime configuration is injected from AWS SSM Parameter Store in `serverless.yml`:

- `HA_ENDPOINT` -> `${ssm:/ha-assistant-skill/ha-endpoint}`
- `CAMERA_ENDPOINT` -> `${ssm:/ha-assistant-skill/camera-endpoint}`
- Alexa Skill ID -> `${ssm:/ha-assistant-skill/id}`

Never hardcode Home Assistant URLs, camera URLs, credentials, or Alexa Skill IDs in code or config files.

## Known Gotchas

- **APL `OpenURL` prerequisite**: Echo Show requires rendering an APL document (`documents/launchDocument.json`) with a matching `token` before executing `Alexa.Presentation.APL.ExecuteCommands` (`OpenURL`). Keep `documents/` packaged in Lambda deployments.
- **Async Lambda handler (`nodejs24.x`+ / `nodejs26.x`)**: AWS Lambda removed callback-based handlers starting in `nodejs24.x`. `ask-sdk-core`'s `.lambda()` helper returns a legacy callback handler, so `index.js` uses `.create()` and exports `async (event, context) => skill.invoke(event, context)` instead.
- **Non-intent errors in `ErrorHandler`**: `src/errorHandler.js` accesses `handlerInput.requestEnvelope.request.intent.name`, which can throw if the failing request is not an `IntentRequest` (e.g., `LaunchRequest` or `SessionEndedRequest`). Use optional chaining (`?.`) if modifying error logging.
- **Build artifacts**: `.serverless/` is generated by Serverless Framework and ignored by ESLint/Prettier; do not edit generated templates manually.
